Version 0.10.1 is a stable release. It includes the image preview and keyboard hook fixes from unlimited.2, plus changes to the Win+V popup and bar-item actions.

## Changes

- Right-click a WindowSill bar item to choose Paste or Copy. Copy updates the clipboard without pasting.
- Win+V chooses a position near the text caret when available, with an active-monitor fallback. Placement happens before display, replacing the saved-position move.
- The popup has multiline cards, search, Clear all, and a close button within 360 by 400 logical pixels.
- Use Up and Down to select, Enter to paste, Ctrl+F to search, and Escape or a second Win+V to close.
- Popup paste checks the target window and process, and skips automatic paste if focus moves elsewhere.
- Search-index updates are batched. Image previews and the keyboard hook remain outside the UI layout path.
- Release assembly debug metadata uses mapped paths instead of the local build directory.

## Install

Requires Windows 11, WindowSill 1.0.3 or newer, and Windows clipboard history enabled.

1. Disable the official Clipboard History extension in WindowSill Settings, under Manage Extensions.
2. For an earlier sideloaded fork, uninstall its extension package and restart WindowSill first.
3. Download `WindowSill.ClipboardHistory.NoLimits.0.10.1.wsext` below, double-click it, and accept the installation prompt.
4. Enable Clipboard History No Limits if needed.

The encrypted history folder remains the same. GitHub update checks report this stable release to earlier versions, but do not install it automatically. WindowSill's marketplace service is separate.

## Validation and limits

All 61 regression tests and 16 native hidden-window placement cases passed. The native probe covered four display scales and generated no keyboard input. The package builds without warnings or errors.

The fork does not exactly reproduce the private Windows Shell placement algorithm. Custom editors can trigger the monitor fallback. Full gameplay, IME, and capture-mode testing remains incomplete. The [Win+V audit](https://github.com/BENZOOgataga/WindowSill-NoClipBoardHistoryLimit/blob/main/docs/win-v-audit.md) records the evidence, fixes, and remaining differences.
