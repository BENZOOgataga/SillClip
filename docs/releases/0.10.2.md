Fixes successive Win+V openings switching to another monitor while the mouse stays still.

The extension now captures the mouse position and target window before queuing popup work. The pointer selects the monitor for that invocation. A text caret is used only when it is on that display; otherwise the popup opens near the pointer. WindowSill's own search caret is excluded from detection.

## Install

Requires Windows 11 and WindowSill 1.0.3 or newer, with Windows clipboard history enabled.

For an earlier sideloaded version, uninstall its extension package and restart WindowSill. Double-click `WindowSill.ClipboardHistory.NoLimits.0.10.2.wsext` below and accept the installation prompt. Keep the official Clipboard History extension disabled.

The encrypted history folder remains the same. GitHub checks report updates but do not install them automatically.

## Validation

All 70 regression tests and 80 native hidden-window placement cases passed. The native tests include repeated openings on a reused window, intermittent caret availability, and four display scales. They generated no keyboard input. A manual replay of Win+V on the user's desktop was not automated.
