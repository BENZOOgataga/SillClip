The clipboard popup now returns to the top every time it opens. Previously, after many copies arrived while the popup was hidden, the virtualized list could reopen at an older position.

Opening from Win+V or the bar clears the previous search, updates layout, selects the first item, and resets scrolling without animation. Pinned items remain first, followed by recent copies. You can scroll through older entries during the current opening.

## Install

Requires Windows 11 and WindowSill 1.0.3 or newer, with Windows clipboard history enabled.

For an earlier sideloaded version, uninstall its extension package and restart WindowSill. Double-click `WindowSill.ClipboardHistory.NoLimits.0.10.3.wsext` below and accept the installation prompt. Keep the official Clipboard History extension disabled.

The encrypted history folder remains the same. GitHub checks report updates but do not install them automatically.

## Validation

The package builds without warnings or errors. The existing 70 unit tests and 80 native placement cases pass. They do not provide an end-to-end test of the WinUI scroll reset.
