First public prerelease of Clipboard History No Limits, a free fork of the official WindowSill extension.

Use [0.10.1-unlimited.2](https://github.com/BENZOOgataga/WindowSill-NoClipBoardHistoryLimit/releases/tag/v0.10.1-unlimited.2) instead. This version can crash WindowSill while loading clipboard image previews during layout, and its keyboard hook shares the UI thread. The next prerelease fixes these paths.

Set Maximum number of items to `0` or `-1` for unlimited retention, or choose a limit such as `500` or `1000`. The extension stores its own encrypted archive while WindowSill is running, so items can survive Windows history eviction and PC restarts.

## Install

Requires Windows 11, WindowSill 1.0.3 or newer, and Windows clipboard history enabled.

1. Open WindowSill Settings, then Manage Extensions, and disable the official Clipboard History extension.
2. Download `WindowSill.ClipboardHistory.NoLimits.0.10.1-unlimited.1.wsext` from the assets below.
3. Double-click the file in File Explorer and accept the WindowSill installation prompt.
4. Enable Clipboard History No Limits if needed, then press Win+V.

Use the `.wsext` asset to install the extension. The source archives are for building it yourself.

The fork has a separate package ID to prevent official marketplace updates from replacing it. Existing encrypted history and pins from the earlier fork are copied on first run; the original files are retained.

## Included

- Win+V opens a 360 by 400 popup with a search field. The shortcut override can be disabled in settings.
- Drag the heading to move the popup. It saves its position and keeps it within the available monitor area.
- Search also opens from the WindowSill bar and works in compact mode.
- Pinned items stay at the top and do not count toward the retention limit.
- Archived images load on demand as thumbnails. Link icons use local resources.
- Password masking applies to detected passwords in the list and preview and excludes them from text search.

## Limits and validation

The extension checks GitHub for updates at startup and every six hours. It does not download or install updates automatically.

Password detection is heuristic. It cannot identify every secret, and masking does not remove content from the encrypted archive. Encryption uses Windows DPAPI for the current account; the archive is not portable to another account or PC.

The popup uses WindowSill's screen recording protection. Capture exclusion depends on the sharing tool and capture mode. The extension does not detect Discord streams.

Validation: 35 automated regression tests passed, the Release package built without warnings or errors, and the extension loaded in WindowSill 1.0.3. A full manual UI pass remains incomplete, including drag placement and Escape behavior. This release is marked as a prerelease.
