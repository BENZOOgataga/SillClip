The GitHub repository is now named SillClip. This release updates the repository links and fixes Open release for the new URL. The extension still appears in WindowSill as Clipboard History No Limits, with the same package ID and encrypted history folders.

## Install

Requires Windows 11 and WindowSill 1.0.3 or newer, with Windows clipboard history enabled.

Earlier builds can detect releases through GitHub's repository redirect, but their release-link check rejects the new repository name. If Open release does nothing, download the package from this page.

For an earlier sideloaded version, uninstall its extension package and restart WindowSill. Double-click `WindowSill.ClipboardHistory.NoLimits.0.10.4.wsext` below and accept the installation prompt. Keep the official Clipboard History extension disabled.
